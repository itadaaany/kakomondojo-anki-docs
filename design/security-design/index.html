    セキュリティ設計書

    1. 概要

    本設計書は、過去問道場×Obsidian×Anki 連携プラグインのセキュリティ設計を定める。本ツールは認証なし・単一ユーザー・ローカルツールであり、外部送信は fe-siken.com への GET と localhost の AnkiConnect 通信のみに限定される。通信・監査・インシデント対応等の運用設計は本書のスコープ外とする。

    2. 認証設計

    2.1 認証方式

    対象外。本ツールは単一ユーザーのローカルツールであり、ユーザー認証を持たない（REQ-OVERVIEW-001 参照）。

    2.2 セッション管理

    対象外。認証機構がないためセッション管理は不要。

    2.3 トークンライフサイクル

    対象外。認証機構がないためトークン管理は不要。

    3. 認可設計

    3.1 認可方式

    対象外。単一ユーザー・ローカルツールのため認可制御は不要。

    3.2 ロール定義

    対象外。ユーザーロールは存在しない。

    3.3 画面アクセスマトリクス

    対象外。Web アプリケーションではなく Obsidian プラグインのため、画面アクセス制御は Obsidian 本体の責務となる。

    3.4 API 権限マトリクス

    対象外。本ツールは REST API サーバを持たない。外部への HTTP リクエストのみ行う（詳細は「5. 通信セキュリティ」参照）。

    3.5 ロール別機能アクセス一覧

    対象外。ロール設計なし。

    4. データ保護

    4.1 暗号化

    対象 方式 備考
    fe-siken.com への通信 HTTPS（TLS） Obsidian requestUrl API 経由。対象外通信なし
    AnkiConnect 通信 なし（HTTP） localhost 限定のため暗号化対象外（後述）
    Vault 上の Markdown なし Obsidian Vault の保護は Obsidian 本体の責務

    AnkiConnect との通信は http://localhost:8765（ループバックアドレス）に限定されるため、外部ネットワークへの平文送信は発生しない（detail-design-context.md: B）。

    4.2 個人情報（PII）取り扱い

    データ種別 保存 備考
    認証情報（ID・パスワード等） 保存しない -
    個人情報 保存しない -
    取得コンテンツ（問題・解説） Vault 上に保存 著作権の帰属は過去問道場および出題元（後述）

    data.json（プラグイン設定ファイル）に秘匿情報を格納しない。設定として保存する値は登録先フォルダ名・Anki デッキ名・AnkiConnect URL・ノートタイプ名・レート制御間隔のみ（detail-design-context.md: H）。

    4.3 データマスキングルール

    対象外。PII を保存しないためマスキング設計は不要。

    5. 通信セキュリティ

    5.1 外部通信の制限

    本ツールが行う外部通信は以下の2種類のみ（REQ-OVERVIEW-001 非機能要件・detail-design-context.md: J）。

    通信先 プロトコル 種別 備考
    https://www.fe-siken.com/kakomon/... HTTPS GET 問題ページ HTML の取得。読み取り専用
    http://localhost:8765 HTTP POST AnkiConnect への JSON リクエスト

    上記以外の外部通信は行わない。

    5.2 URL バリデーション

    取り込み対象 URL は以下の条件を満たすもののみ受け付ける（detail-design-context.md: G）。

    検証項目 許可値
    ホスト fe-siken.com または www.fe-siken.com
    パス /kakomon/ から始まること

    バリデーションに失敗した URL は処理を中断し、エラーを表示する。

    5.3 AnkiConnect 通信

    • エンドポイントは http://localhost に限定される（デフォルト: http://localhost:8765）
    • 外部ホストへ変更可能な設定項目ではあるが、設計上の想定は localhost のみ

    6. 入力検証とサニタイズ

    6.1 取り込み URL の検証

    「5.2 URL バリデーション」参照。

    6.2 HTML 抽出時のサニタイズ

    HTML の解析は Obsidian/Electron の DOMParser を使用する（detail-design-context.md: A）。

    Anki カードのフィールド（問題文・選択肢・解説等）に HTML を埋め込む場合、意図しないスクリプト実行を防ぐため、スクリプトタグ・イベントハンドラ属性等の除去を考慮すること。

    ※ 要確認: Anki カードへの HTML サニタイズの具体的な方法（使用ライブラリ・除去対象タグ）は実装時に確定させること。

    7. CORS 設定

    AnkiConnect の webCorsOriginList に追加するオリジンは app://obsidian.md のみとし、不要なオリジンを許可しない（最小権限の原則）（detail-design-context.md: B・REQ-OVERVIEW-001 参照）。

    {
  "webCorsOriginList": [
    "app://obsidian.md"
  ]
}

    8. スクレイピング倫理・コンプライアンス

    本ツールは以下の方針に従う（REQ-OVERVIEW-001 法的・コンプライアンス要件）。

    項目 方針
    用途 個人の学習用途に限定する
    アクセス頻度 fe-siken.com への連続アクセスは1秒以上の間隔を空ける（レート制御間隔デフォルト: 1000ms）
    利用規約・robots.txt fe-siken.com の利用規約および robots.txt を尊重する
    コンテンツ再配布 取得したコンテンツを再配布しない（個人のローカル学習のみ）
    著作権帰属 取得した問題・解説の著作権は過去問道場および出題元に帰属する
